Informasi

Project ID, branch, dan API token disimpan di localStorage perangkat ini. Daftar map juga di-backup secara lokal, jadi tombol “Load” hanya perlu dipakai untuk mengambil data terbaru dari server. Foto, owner, dan jumlah online game diambil dari Roblox lewat proxy publik (roproxy). Perubahan (tambah/ubah) dikirim sebagai satu pesan changelog ke Discord lewat /api/discord-notify.
